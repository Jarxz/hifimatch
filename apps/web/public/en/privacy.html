Privacy

Your setup, in your browser.

No accounts. No tracking cookies. This page says exactly what's stored, where, and why.

No account, no server

The Hifi Match doesn't ask you to create an account or sign in. The compatibility analysis runs entirely in your browser: room measurements, the equipment you choose, and the result are never sent to a server or stored in a database.

Aggregated analytics

The site uses Vercel Web Analytics to count visits in an aggregated, anonymous way. It uses no cookies: each visitor is recognized by a hash derived from the request, discarded after 24 hours — never a persistent identifier that follows the same person across visits. What's recorded per visit is aggregated (approximate country/city, device type, browser, which page was viewed and where it came from) and is never tied to a stored IP address or an identifiable person.

Contact form

The only personal data this site receives is what's voluntarily typed into the contact form (optional name, email, and message). That submission is processed through an email provider (Resend) and goes straight to the site's contact inbox — it isn't stored in any database of ours, nor shared with anyone else. The form includes automatic checks against automated submissions (a hidden field and a minimum-time check) that don't collect any additional data about the person writing.

Public message wall

This site also has a public message wall. The name (if given) and the message text are stored in a database (Upstash Redis) and shown to any visitor — it's public content, not private. The email address requested alongside the message is stored too, but never shown publicly: it's only used if a reply is needed by that channel. None of this touches the compatibility analysis (room measurements, chosen equipment, result), which still never leaves the browser.

My systems

Saving a system under "My systems" stays only in your own browser's local storage — no account, no sync across devices. None of it reaches a server; clearing your browser's history also clears those saved systems.

Hosting logs

As with any site on the internet, the hosting provider (Vercel) logs basic technical information for each request (for example, IP address) for infrastructure operation and security purposes — this site does not access those logs for tracking purposes.
